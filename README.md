# Iomico Zephyr Training 2026

This project entails several of the assignments from Iomico company's Zephyr
RTOS training course of 2026.  Tagged commits represent working assignments
per the author's testing with specific hardware.  These applications written
in C are based on Zephyr 4.3.0

flash the applications.  Some notes there also on expected output.
